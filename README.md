# JFMCSS Control

High-fidelity administrative workspace prototype for JFMCSS.

## Modules included

- Executive dashboard and next-best-action workspace
- Client 360 / CRM
- Sales pipeline
- Projects and profitability
- Dominican billing / NCF & e-CF readiness
- Collections and recurring revenue
- Support desk with SLA
- Infrastructure, assets and renewal watch
- Omnichannel notifications
- Automations
- Reports and configuration

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Branding

The interface follows the existing JFMCSS visual language from `infoboy27/jfmcss-ui`: dark navy background, blue/cyan gradients, Space Grotesk-inspired typography, monospace data labels, translucent cards and subtle borders.
